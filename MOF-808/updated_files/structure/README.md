# Structure Files

`mof808_empty.data` is the empty MOF-808 framework. `mof808_1040wat.data` is the hydrated framework containing 1040 water molecules.

In the hydrated data file, atom types 12 and 13 are the water oxygen and hydrogen types used by the MBX `h2o` monomer mapping in `inputs/in.mof_water`. The water model is selected by the LAMMPS input; the structure file supplies coordinates, topology, and atom types.
