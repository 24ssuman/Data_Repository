# Scripts and Figures for Microsolvation of Protonated Glycine: Infrared Spectra from Data-Driven Quantum Many-Body Simulations



1. ```deepmd-qc-training```: contains json file of the parameters used in the qc@mb-nrg training
2. ```figures```: contains all scripts and data files used to make main text and SI figures from the paper
3. ```infrared-spectra```: contains example json files for calculating IR spectra (using MB-SPEC)
4. ```power-spectra-decomposition```: contains example script for calculating a spectra decomposition using velocity-velocity time correlation function
5. ```remd-scripts```: contains example script for calculating REMD isomers from simulation (using MB-Tools add-on to MBX)
6. ```reverse-spectral-reconstruction```: contains example script for reverse spectral reconstruction fitting
7. ```simulations```: contains example input scripts for classical and te-pigs simulations
